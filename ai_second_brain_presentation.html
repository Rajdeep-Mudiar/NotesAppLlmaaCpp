The "Local First" AI Engine

⚙️

How It Works

C++ backend communicates with background llama-server process via HTTP/1.1 POST requests. The model remains resident in RAM for instant inference.

🚀

Ultra-Low Latency

Model kept in system RAM eliminates cold-start delays. Custom C++20 server significantly outperforms interpreted backends like Python or Node.js.

🛡️

Reliability

Automatic fallback to llama-cli if the server process hangs or becomes unresponsive. Health checks ensure 99.9% uptime.

🔒

Absolute Security

Your private thoughts never leave your machine. Zero external API calls to OpenAI, Anthropic, or any third-party service for note processing.
